👉 点击安装脚本 (Greasy Fork)

需要先安装 Tampermonkey 插件

🚀 核心功能

🖐️ 自由拖拽面板

全新的悬浮面板设计，不再遮挡页面内容。按住标题栏即可随意拖动，位置自动记忆。

🧠 自动模式识别

能够自动识别当前是“草稿列表”还是“失败列表”，智能切换运行逻辑，无需手动设置。

♻️ 失败断点重跑

针对 Failed 任务，脚本会自动执行 Clone -> Resubmit 流程，在原参数基础上快速重试。

🖱️ 强力交互引擎

内置文字搜索点击技术，精准定位 Confirm 和 Menu 按钮，即使弹窗有动画延迟也能稳定触发。

2. 运行流程

  1. 进入列表页： 根据你的需求，点击 AF3 左侧菜单进入 Saved Drafts 或 Failed jobs。
  2. 调整每页显示： 建议在页面底部将 Rows per page 设置为 100，以减少翻页烦恼。
  3. 设置数量： 在黑色面板输入框中，输入想要连续处理的任务数量（例如 10）。
  4. 一键启动： 确认面板底部提示文字无误后，点击 🚀 启动。
  5. 保持前台： 脚本运行期间，请勿关闭页面或最小化浏览器，这可能会导致模拟点击失效。

⚠️ 免责声明 & 常见问题

提示： 脚本会自动跳过因为配额（Daily Quota）不足而弹出的报错，这属于正常现象。
提示： 使用Edge浏览器时，请确保已启用“允许网站在后台运行脚本”等设置，以确保脚本正常工作（有3个设置）。
面板不显示： 请先确认 Tampermonkey 中脚本已更新到 V2.2 且处于启用状态，然后刷新 https://alphafoldserver.com/。V2.2 已增强面板注入逻辑，可兼容 AlphaFold Server 页面重绘和 www 域名。
  • 关于失败重跑： 脚本通过点击 "Clone and reuse" 实现重跑。该过程会产生页面跳转，速度较慢，请耐心等待脚本“补刀”。
  • 如果卡住了： 极少数情况下如果网络卡顿导致弹窗未关闭，您可以手动帮它点一下 Confirm，脚本会自动检测变化并继续。
